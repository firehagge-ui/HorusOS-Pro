# Fontes registradas (URLs de CSV publicado do Spark)

Cada linha é uma planilha do Spark publicada na web como CSV. O Horus lê daqui
pra saber onde buscar. Registrar a URL uma vez; o dado muda, a URL fica.

Como publicar: no Google Sheets → `Arquivo → Compartilhar → Publicar na web →`
escolher a aba → formato **CSV** → copiar a URL gerada (termina em `output=csv`).
