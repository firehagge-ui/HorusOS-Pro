# Logs do Conselho

Cada sessão de `/conselho` grava aqui um arquivo
`AAAA-MM-DD-<assunto>.md`, no formato de `../templates/LOG-CONSELHO.md`.

Duas razões para o log existir:

1. **Decisão que morre no chat volta como pergunta na semana seguinte.** O Claude
   não guarda nada entre conversas: só existe o que está em arquivo.
2. **O log guarda a divergência, não só a decisão.** Quando algo der errado, o
   valor está em ver quem tinha avisado e por quê. É assim que o Conselho fica
   mais afiado em vez de repetir o mesmo erro com formatação bonita.

Sessão que virou escalação para o Marcelo também vira log, com as opções que
foram apresentadas. Depois que ele decidir, anotar a escolha no bloco final
"O que aconteceu depois".
